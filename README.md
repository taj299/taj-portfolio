## 🔐 Admin Dashboard

The portfolio includes a private admin dashboard.

Admin features include:

- Add projects
- Edit projects
- Delete projects
- View portfolio statistics
- View contact messages

Admin APIs are protected using authentication.

## 🗄️ Database

Cloudflare D1 is used for storing:

- Portfolio projects
- Portfolio view statistics
- Contact form messages

## 🌐 Deployment

The portfolio is deployed using Cloudflare Workers.

The project uses Cloudflare D1 for database functionality.
